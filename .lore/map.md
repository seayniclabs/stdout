# Lore architecture map

_Generated by Lore. Use this to find which files/areas a change concerns before reading code._

- Frontend — Server-rendered Astro pages, layouts, and components for the HUD, dashboards, setup wizard, docs, and status pages
- Backend — Astro Node server with API endpoints and lib services for scanning, discovery, diagnostics, observatory/sentinel logic, and business rules
- Database — Local SQLite store with Drizzle schema and migrations for hosts, incidents, entities, skins, and audit data
- Auth — Password hashing, session middleware, RBAC, license validation, and API token management
- Integrations — External connectors for AI diagnosis, email/Slack notifications, ticketing, metrics ingestion, and CVE/Docker scanning
- Infrastructure — Containerized deployment with observatory monitoring stack and Python sentinel agents for watching and analysis
