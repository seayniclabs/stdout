═══════════════════════════════════════════════════════════════════════════════
CRITICAL GAPS (Phase 1 — Do First)
═══════════════════════════════════════════════════════════════════════════════

[P1-A] Observatory Page Cognitive Overload — 4–6 days
  ┌─ Problem: Too many controls competing for attention
  ├─ Impact: High — users don't know where to start
  ├─ Root cause: No progressive disclosure; all features visible at once
  ├─ Solution: Collapse "Advanced Controls", add inline guidance, clear workflow
  └─ Status: CRITICAL

[P1-B] Missing Accessibility Labels — 1–2 days
  ┌─ Problem: SVG icons, toggles, severity indicators lack ARIA labels
  ├─ Impact: High — screen reader users can't use app
  ├─ Examples: Nav icons, status dots, mode buttons, toggles
  ├─ Solution: Add aria-label, role="img", role="status", role="switch"
  └─ Status: CRITICAL

[P1-C] No Loading/Empty/Error States — 3–4 days
  ┌─ Problem: Users get no feedback when pages load or actions fail
  ├─ Impact: High — app feels broken or unresponsive
  ├─ Gaps: No spinners, skeleton loaders, empty illustrations, error toasts
  ├─ Solution: Add feedback UI for all 3 states (loading/empty/error)
  └─ Status: CRITICAL

MEDIUM PRIORITY (Phase 2 — Do Next)
═══════════════════════════════════════════════════════════════════════════════

[P2-A] Component Styling Inconsistency — 2–3 days
  Multiple button classes with different hover behavior
  Input fields styled differently on auth vs. app pages
  → Solution: Standardize to single .btn-* and .input class systems

[P2-B] Mobile Responsiveness Gaps — 2–3 days
  Observatory, Settings pages break on small screens
  Mode ladder becomes 3-row stack (full vertical height)
  → Solution: Add mobile breakpoints, hide non-essential cards, responsive grid

[P2-C] Form Validation Missing — 1–2 days
  No real-time feedback on inputs
  No password strength meter, success/error states
  → Solution: Field-level validation, real-time feedback, success toast

LOWER PRIORITY (Phase 3 — Polish)
═══════════════════════════════════════════════════════════════════════════════

[P3-A] Animation Performance — 2–3 days
  Neural background recalculates connections every frame (O(n²))
  Body orbs animation uses expensive blur filter on every page
  → Solution: Throttle calculations, reduce node count on mobile

[P3-B] No Component Library — 5–7 days
  56 pages define forms/buttons/cards inline (heavy duplication)
  No design system documentation
  → Solution: Extract 8–10 reusable Astro components, create design guide

[P3-C] Weak Onboarding — 3–4 days
  Onboarding checklist is silent and dismissible
  No guided walkthrough or contextual help
  → Solution: Redesign checklist as prominent card, add tooltips

[P3-D] Design System Documentation — 2–3 days
  No guide for developers on component usage, spacing, colors
  → Solution: Create DESIGN_SYSTEM.md + component showcase page
